> 
> 💡 **Nola erabili egutegi hau:**
> * Egun bakoitzean landutako **asignatura / modulua** jarri.
> * Asignatura bakoitzaren barruan bete 3 atalak: **Sin hacer**, **Haciendo** eta **Hecho**.
